# MagaBot

Telegram-бот «Мага» — собеседник с характером. Работает только на бесплатных моделях OpenRouter.

## Как с ним говорить

- в группе: начните сообщение с «Мага, …» или ответьте на его сообщение;
- в личке: просто пишите;
- фото: пришлите с подписью «Мага, …» (или в личке, или ответом на его сообщение);
- голосовые: в личке или ответом на его сообщение — Мага распознает речь и ответит текстом;
- иногда Мага сам встревает в разговор группы (не чаще раза в 15 минут);
- `/toast [повод]`, `/advice [тема]`, `/roast` (ответом на сообщение), `/reset` — забыть разговор.

## Запуск

```bash
docker build -t magabot .
docker run -d --restart unless-stopped \
  -e API_TOKEN=<токен от @BotFather> \
  -e OPENROUTER_API_KEY=<ключ OpenRouter> \
  magabot
```

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `API_TOKEN` | — | токен бота (обязательно) |
| `OPENROUTER_API_KEY` | — | ключ OpenRouter (обязательно) |
| `MODELS` | `google/gemma-4-31b-it:free,nvidia/nemotron-3-ultra-550b-a55b:free,openrouter/free` | модели для текста, пробуются по очереди |
| `VISION_MODELS` | `google/gemma-4-31b-it:free,nvidia/nemotron-3.5-super-vl:free,openrouter/free` | модели для фото |
| `AUDIO_MODELS` | `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free` | модель для распознавания голосовых |
| `DAILY_LIMIT_USER` | 20 | запросов в сутки от одного человека |
| `DAILY_LIMIT_CHAT` | 100 | запросов в сутки на чат |
| `INTERJECT_CHANCE` | 0.03 | шанс, что Мага сам встрянет в разговор (0 — выключить) |
| `INTERJECT_COOLDOWN` | 900 | минимум секунд между такими репликами в одном чате |
| `GROUP_CONTEXT` | 20 | сколько последних сообщений группы видит Мага |
| `MAX_HISTORY` | 14 | сколько последних реплик диалога помнить |
| `COOLDOWN_SECONDS` | 2 | минимальная пауза между вопросами одного человека |
| `REQUEST_TIMEOUT` | 60 | таймаут запроса к модели, сек |

Бесплатные модели OpenRouter ограничены по числу запросов в сутки на аккаунт, поэтому у бота есть свои дневные лимиты. Список бесплатных моделей меняется — актуальный можно посмотреть на openrouter.ai/models (фильтр по цене Free).

Чтобы Мага видел обычные сообщения группы («Мага, …», контекст разговора), у бота должен быть выключен privacy mode в @BotFather (`/setprivacy` → Disable) или бот должен быть админом группы.
